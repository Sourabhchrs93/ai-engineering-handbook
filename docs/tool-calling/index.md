# Tool calling

Tool calling is the boundary between probabilistic decisions and deterministic code. This section covers schemas, argument validation, permissions, execution, error handling, and how identity stays out of model control.

Start with [tool calling](tool-calling.md). Retries, timeouts, and lost responses are covered with the agent loop in [agents and tool use](../agents/agents-and-tool-use.md), and duplicate side effects in [checkpointing and recovery](../memory/checkpointing-and-recovery.md).
